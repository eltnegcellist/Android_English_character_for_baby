## 学習器の制限・公開条件

- PR-BはTopic×Interactionの合成日本語98件を追加し、477件の暫定人工テキストで再学習。最後のtestは76件で64件正解（84.21%）だが、**14クラスはそれぞれわずか3テスト例**。この値を実家庭の精度と呼ばない。
- TopicとInteractionは**Ruri出力だけ**で独立採否判定（Topic確率0.50以上・差0.05以上、Interaction確率0.50以上）。日本語のキーワード・否定・質問マッチングは両軸の分類に使わない。2分類器の確率を直接比較しない。
- **初期公開はInteractionの実験スイッチOFFのまま**。人手ラベル審査・実音声試験・Kikiレビュー・Android実機動作が完了するまでは全ユーザーでONにしない。
- 全ゲート未完了のため、現段階でGitHub mainへのマージやPlay配布、一般ユーザー向けのバージョンアップは**保留**。
- RC APKはGitHub ActionsのPR #38に添付される場合がある。CIが成功したArtifactだけを取得し、インストール後の端末テストはユーザー自身またはMac上Codexが担当する。完成宣言・リリースノートに「検証済み」と誤記しない。

## 既知の残課題

- 似た褒め言葉、自然なASR誤認を多く含む独立試験データがない。
- 111組のTopic×Interactionには固定英文333セットを用意。両軸が採用されてもペア英文がない組み合わせはTopic英文に戻し、未知の組み合わせを動的につなぎ合わせない。
- 標準の名称挿入は既存197セットだけで、新112セットは固定英文・名前なし（3文/語数の安全性を優先）。
- AndroidとWebは同一学習済みInteraction head（SHA256一致）を使用するが、Java Native ORTとWeb WASMの実際の埋め込み一致テストが一部CIで失敗。**原因が確定するまでAndroidの精度保証・一般公開は禁止**。
- CIは構文・ユニットテスト・限定的な実モデル推論であり、自然さや赤ちゃんへの学習効果を測定しない。
