## 学習器の制限・公開条件

- PR-Bは383件の暫定人工テキストで学習・検証。最後のtestは63件で57件正解（90.48%）だが、**14クラスはそれぞれわずか2テスト例**。この値を実家庭の精度と呼ばない。
- `interaction.head`の単独softmaxを既存Topicと直接比較しない。現実の発話では明確な育児Topicを優先し、不確かなInteractionは棄却。
- **初期公開は実験スイッチOFFのまま**。人手ラベル審査・実音声試験・Kikiレビュー・Android実機動作が完了するまでは全ユーザーでONにしない。
- 全ゲート未完了のため、現段階でGitHub mainへのマージやPlay配布、一般ユーザー向けのバージョンアップは**保留**。
- RC APKはGitHub ActionsのPR #38に添付される場合がある。CIが成功したArtifactだけを取得し、インストール後の端末テストはユーザー自身またはMac上Codexが担当する。完成宣言・リリースノートに「検証済み」と誤記しない。

## 既知の残課題

- 似た褒め言葉、自然なASR誤認を多く含む独立試験データがない。
- `遊ぼうか`など具体TopicとInteractionが共存する場合は最初は現行Topic優先。将来のTopic×Interaction統合は別PR。
- 標準の名称挿入は既存197セットだけで、新112セットは固定英文・名前なし（3文/語数の安全性を優先）。
- AndroidとWebは別言語実装の正規化ルールで、特に句読点の組み合わせを実機で再検証する。
- CIは構文・ユニットテスト・限定的な実モデル推論であり、自然さや赤ちゃんへの学習効果を測定しない。
