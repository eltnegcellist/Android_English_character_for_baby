# 通常の呼びかけ：リズム優先の英文レビュー（2026-10-14）

## 背景と変更内容
保護者の実聴感想：「押して聞く」は短い声かけとリズムが楽しいが、通常の呼びかけは説明的・抽象的で難しい。

- 全体の対象：Topic 197セット、Interaction 112セット、Topic×Interaction 495セット＝**804セット**。
- 本PRで**個別に推敲・修正したのは105セット**（Topic 14、Interaction 23、組み合わせ 68）。804件すべてを手作業で改稿したわけではない。
- 手本は「押して聞く」の短い直接的な声かけ・場面に合った擬音・音の反復。
- 「押して聞く」の22話題・110セット、および1文/3文切替は変更しない。分類・判定閾値・Ruri・TTSも対象外。
- Web / Androidで同じ元の英文を、同じ新しい英文に置き換える。

## 編集基準
- `What do you notice?`、`I'm proud of you` などの抽象的・説明的な繰り返しを減らし、`Sip, sip, sip!`、`Kick, kick, kick!`、`Drip, drop, drip!` のように場面ごとの音に寄せる。
- 1セット3文・合計6～12英単語・1文最大4英単語の制約を保つ。
- Interactionの意図（例：確認なら質問、安心なら寄り添い、努力なら達成を断定しない）を維持する。
- 抽象語を単一の新しい定型句へ置き換えすぎないよう、場面ごとに違う具体語を使う。

## テストの境界
- 105件の元英文がWeb/Android双方に1件ずつ存在することを照合した。
- 新英文の文数・語数を機械確認した。「押して聞く」のJSONがWeb/Androidで同一であることも確認した。
- ただし**英語母語話者による全804セットの個別審査、Kiki実音声の聴き比べ、端末上での自然な抑揚チェックは未実施**。これをもって本番APKへ自動採用しない。
- 改善差分を確認し、実聴A/Bと既存CIの確認後に採用判断する。
